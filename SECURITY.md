# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The Milo team takes security seriously. If you discover a security vulnerability within Milo, please do **not** open a public issue.

Instead, please send an advisory email directly to:

**security@milo.app**

Please include:
- A description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal proof of concept.
- Any suggested mitigations if available.

### What to Expect
- **Initial Response**: We will acknowledge receipt of your vulnerability report within 48 hours.
- **Triage & Assessment**: We will assess severity and coordinate a fix in a private branch.
- **Release & Disclosure**: Once a patch is released, we will publish a security advisory giving you public credit (unless you prefer anonymity).
